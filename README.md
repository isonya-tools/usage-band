# UsageBand

Claude の5時間枠・週間枠の使用率を、Windows のデスクトップに常に表示するアプリです。

- 5時間枠・週間枠の使用率バー、ペースの縦線、リセット時刻を表示
- Claude のチャット、Claude Code、Cowork など、すべての使用量が反映されます(約30秒ごとに更新)
- 常に最前面に表示。位置、大きさ、クリック透過をタスクトレイのメニューから切り替え
- 大きさは左右の端をドラッグして変更(文字もバーも一緒に拡大・縮小)

## 仕組み

Claude にログインした情報を使って、Claude の使用率 API を直接呼び出します。使用率 API は非公式のため、Claude 側の仕様変更で動かなくなる可能性があります。

- ログイン情報は、このパソコンの `%USERPROFILE%\.claude\.credentials.json` を読みます(`claude auth login` で作られます)。
- トークンは Claude の公式サーバーにだけ送られ、それ以外には送信しません。
- トークンの期限が切れたときは、アプリが自動で更新して同じファイルに保存します。

## インストール

1. Windows PowerShell を開く
2. 次のコマンドを貼り付けて Enter

```powershell
irm https://raw.githubusercontent.com/isonya-tools/usage-band/main/install.ps1 | iex
```

3. ブラウザが開いたら、Claude にサインインする(初回のみ)
4. `[DONE]` と出れば完了。画面右下のタスクトレイにアイコンが出ます

すでに入っている場合は、同じコマンドで最新版に更新されます。

Claude Code(`claude` コマンド)がインストール済みであることが必要です。

## 設定

タスクトレイのアイコン、または表示そのものを右クリックすると、設定メニューが出ます。

- **常に前面に表示(クリック透過)**: チェックを入れると、常に最前面に表示され、クリックは下のウィンドウに通ります。クリックが通るため、位置も大きさも変えられません(下の2項目はグレーアウト)。チェックを外すと、すぐに位置と大きさを変えられ、通常のウィンドウとして他のウィンドウの後ろに隠れます。
- **位置を固定する**: チェックなしだと、ドラッグで自由に動かせる(ディスプレイをまたいで移動可能)
- **大きさを固定する**: チェックなしだと、左右の端をドラッグして大きさを変えられる
- **全体を透過(50%)**: 文字やバーも含めて、全体を半透明にする
- **背景のみ透過(50%)**: 背景だけを半透明にして、文字とバーははっきり表示する(2つは同時に選べません。両方オフで不透明)
- **Windows 起動時に自動で起動**

位置は、ディスプレイの大きさと配置を基準に保存されるため、パソコンを再起動しても同じディスプレイの同じ場所に戻ります。

## アンインストール

Windows の「設定」→「アプリ」→「インストールされているアプリ」から「UsageBand」を削除します。

## 開発

```powershell
npm install
npm start          # 起動
npm run shot       # サンプルデータで画像を出力(shot.png)
npm run dist       # インストーラーを作成(dist/)
```
