# UsageBand

Claude の5時間枠・週間枠の使用率を、Windows のデスクトップに常に表示するアプリです。

- 5時間枠・週間枠の使用率バー、ペースの縦線、リセット時刻を表示
- Claude Code を使っている間は、リアルタイムに近い更新。チャットなど Claude Code 以外の使用量は、約5分ごとの更新で反映されます
- 常に最前面に表示。位置、大きさ、クリック透過をタスクトレイのメニューから切り替え
- 大きさは左右の端をドラッグして変更(文字もバーも一緒に拡大・縮小)

## 仕組み

使用率は、次の2つの経路から取ります。

1. **Claude Code の mod(通常はこちら)**: Claude Code を使っている間は、mod が Claude Code の持つ使用率をファイルに書き出し、アプリがそれを読みます。mod の更新が5分以内なら、API は呼びません。
2. **使用率 API(mod が更新されていないとき)**: mod が5分以上更新されていないときだけ、Claude の使用率 API を約5分おきに呼びます。チャットの使用量もこちらで反映されます。
3. **アイドル中は API を呼ばない**: Claude Code(mod)が30分以上動いていないあいだは、API を呼びません。起動した直後の1回と、タスクトレイの「今すぐ更新」を押したときだけ、1回呼びます。mod を使っていない場合(mod 未導入)は、API だけで約5分おきに更新します。

**注意(必ずお読みください)**
- 使用率 API は非公式です。Claude 側の仕様変更で、予告なく動かなくなる可能性があります。
- この API は回数制限が厳しく、アクセスが多いと「しばらく待つ」状態(HTTP 429)になることがあります。そのため API の更新は約5分おきで、断られたときは待ち時間を 5分→10分→20分→30分と延ばし、その間は前回の値を薄く表示します。再起動しても、この待ち状態は引き継ぎます。
- API の認証には、このパソコンの `%USERPROFILE%\.claude\.credentials.json`(`claude auth login` で作られるログイン情報)を使い、トークンは Claude の公式サーバーにだけ送ります。期限が切れたときは、アプリが自動で更新して同じファイルに保存します。
- Anthropic は、サブスクリプションのログイン情報を第三者のツールで使うことを規約で制限していると報じられています。このアプリは使用率を読むだけでモデルは呼びませんが、規約上の扱いは確認できていません。利用は自己責任でお願いします。

## インストール

1. Windows PowerShell を開く
2. 次のコマンドを貼り付けて Enter

```powershell
irm https://raw.githubusercontent.com/isonya-tools/usage-band/main/install.ps1 | iex
```

3. ブラウザが開いたら、Claude にサインインする(初回のみ)
4. `[DONE]` と出れば完了。画面右下のタスクトレイにアイコンが出ます
5. Claude デスクトップアプリを閉じて、開き直す(Claude Code が mod を読み込みます)

すでに入っている場合は、同じコマンドで最新版に更新されます。

Claude Code(`claude` コマンド)がインストール済みであることが必要です。mod は、このリポジトリの `mod` フォルダにあります。

## 設定

タスクトレイのアイコン、または表示そのものを右クリックすると、設定メニューが出ます。

- **今すぐ更新**: 使用率を1回だけ取り直す(429 の待ち中は待つ)
- **常に前面に表示(クリック透過)**: チェックを入れると、常に最前面に表示され、クリックは下のウィンドウに通ります。クリックが通るため、位置も大きさも変えられません(下の2項目はグレーアウト)。チェックを外すと、すぐに位置と大きさを変えられ、通常のウィンドウとして他のウィンドウの後ろに隠れます。
- **位置を固定する**: チェックなしだと、ドラッグで自由に動かせる(ディスプレイをまたいで移動可能)
- **大きさを固定する**: チェックなしだと、左右の端をドラッグして大きさを変えられる
- **透過 50% / 透過 80%**: 背景だけを半透明にして、文字とバーははっきり表示する(数字は背景の不透明度。2つは同時に選べません。両方オフで不透明)
- **Windows 起動時に自動で起動**

位置は、ディスプレイの大きさと配置を基準に保存されるため、パソコンを再起動しても同じディスプレイの同じ場所に戻ります。

## アンインストール

1. Windows の「設定」→「アプリ」→「インストールされているアプリ」から「UsageBand」を削除する
2. mod も外す場合は、PowerShell で次を実行する

```powershell
~\.local\bin\claude.exe plugin uninstall usage-band
```
