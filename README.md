# UsageBand(利用状況ビュー for Claude)

Claude の5時間枠・週間枠の使用率と実行中の状態を、Windows のデスクトップに常に表示するツールです。

- 画面の好きな位置に、常に最前面で表示
- 位置の固定、大きさの固定、クリック透過をタスクトレイのメニューから切り替え
- 大きさは左右の端をドラッグして自由に変更(文字もバーも一緒に拡大・縮小)
- ディスプレイをまたいで移動可能

## 仕組み

2つの部品を、ひとつのコマンドでまとめてインストールします。

| 部品 | 役割 |
|---|---|
| mod(このリポジトリ) | Claude Code の使用率と実行状況を、パソコン内のファイルに書き出す |
| Windows アプリ(Releases にあるインストーラー) | そのファイルを読んで、デスクトップに表示する |

mod は Claude Code の画面には何も表示しません。表示はアプリだけが行います。

## インストール

1. Windows PowerShell を開く
2. 次のコマンドを貼り付けて Enter

```powershell
irm https://raw.githubusercontent.com/isonya-tools/usage-band/main/install.ps1 | iex
```

3. `[DONE]` と出たら、Claude デスクトップアプリを閉じて、開き直す
4. Code タブで新しいセッションを始める

すでに入っている場合は、同じコマンドで最新版に更新されます。

使用率は、Claude Code を動かしている間に更新されます。

## 設定

タスクトレイのアイコン、または表示そのものを右クリックすると、設定メニューが出ます。

- **表示切り替え**: パターン1(バーの右に動作表示)/ パターン2(上の行に動作表示・経過時間・リセット日時)
- **常に前面に表示**: チェックを入れると、常に最前面に表示され、クリックは下のウィンドウに通ります。このあいだは位置と大きさを変えられません(下の2項目はチェック済みでグレーアウト)。チェックを外すと、通常のウィンドウとして他のウィンドウの後ろに隠れます。
- **位置を固定する**: チェックなしだと、ドラッグで自由に動かせる(ディスプレイをまたいで移動可能)
- **大きさを固定する**: チェックなしだと、左右の端をドラッグして大きさを変えられる(文字もバーも一緒に拡大・縮小)

位置や大きさを変えるには、「常に前面に表示」を外し、「位置を固定する」「大きさを固定する」のチェックを外します。

## アンインストール

1. Windows PowerShell を開く
2. 次のコマンドを貼り付けて Enter

```powershell
~\.local\bin\claude.exe plugin uninstall usage-band
```

3. Windows の「設定」→「アプリ」→「インストールされているアプリ」から「UsageBand」を削除
